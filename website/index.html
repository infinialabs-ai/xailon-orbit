Features

Built for being away from the keyboard

Keep work moving from the couch, the train or a meeting, without exposing your machine to the internet.

XailonCode by default

XailonCode is the built-in default agent. Use your installed xailon CLI and models, or let XailonOrbit fetch it for you.

Approve from anywhere

Allow or deny permission requests and answer your agent's questions in a tap. Requests wait for you, even across reconnects.

Know when it's done

Get a push notification when a task finishes. Notifications carry only IDs, never your prompts or code.

Review real work

Browse files, Git changes, diffs and history. Preview the HTML pages, charts and maps your agent builds.

Talk to your agent

Push-to-talk voice chat, with a short spoken summary of every reply when you are on the move.

Watch it live

See the iOS Simulator, Android emulator or browser tab your agent is driving, frame by frame.

One app, every agent

Switch agents, models and modes from your phone. Built on the open Agent Client Protocol (ACP).

Built to keep running

The daemon starts with your computer, drafts survive restarts, and it can keep your machine awake while agents work.

Self-serve by design

No account, no sign-up. Use the hosted relay, or run your own with Docker or on your own Cloudflare account.

How it works

Your phone, your computer, nothing in between

xailon-orbitd runs next to your agents and connects out to a relay, so there are no ports to open and no VPN to set up. The relay only forwards ciphertext.

Get started

Up and running in a minute

Three steps, no account. The user guide covers every option in detail.

Install the daemon

On the computer where your agents run.

curl -fsSL https://xailon-orbit.infinialabs.ai/install.sh | sh
irm https://xailon-orbit.infinialabs.ai/install.ps1 | iex
brew install infinialabs-ai/tap/xailon-orbitd

Start it and scan

It runs in the background, starts with your computer and prints a pairing QR code.

xailon-orbitd start

Pick an agent and go

Scan the code in the XailonOrbit app and choose XailonCode. Want to try it with no API key? Choose Free.

Security

Your code stays on your machine

The phone and the computer pair with a secret ID from the QR code and derive their encryption keys from it.

  • End-to-end encrypted. XChaCha20-Poly1305 with HKDF-SHA256 keys. The relay routes by a derived ID and never sees the pairing secret.
  • No inbound ports. The daemon connects out over WebSocket, so nothing on your computer is exposed.
  • No accounts, no tracking. No sign-up and no analytics. Notifications carry only agent and session IDs.
  • Rotate anytime. xailon-orbitd reset issues a new pairing ID and disconnects every device.
  • Self-host the relay. Run it with Docker or on your own Cloudflare account, then point the daemon at it.
FAQ

Questions, answered

Do I need an account?

No. Pairing uses a secret ID that the daemon generates. Nothing is tied to an email, a phone number or an Infinia Labs account.

Which agents can I use?

XailonCode is the default. Any agent that speaks the Agent Client Protocol also works, including Claude Code, Codex, Cursor, GitHub Copilot, OpenCode, Qwen Code and Kimi CLI. XailonOrbit uses an agent's CLI if you have it installed, and otherwise downloads a managed copy.

Does my code go through Infinia Labs servers?

Only as ciphertext. The hosted relay forwards encrypted frames between your devices and cannot read them. You can also run your own relay.

Can several phones connect to one computer?

Yes. Every device that scans the QR code shares the same sessions. To remove access, run xailon-orbitd reset and pair your devices again.

What does it cost?

XailonOrbit is free and open source under the MIT license. Agents use their own providers, so XailonCode uses the models you configure for it.
